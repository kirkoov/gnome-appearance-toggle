# GNOME Appearance Toggle

A lightweight GNOME Shell extension that adds a panel button to instantly switch between Light and Dark appearance.

## Features

Toggle between Light and Dark appearance with a single click.

- Planned: automatic synchronization with GNOME Night Light.
- Uses the native GNOME `GSettings` API.
- Lightweight, with no external dependencies.

## Technologies

- JavaScript (GJS)
- GNOME Shell Extensions
- Gio / GSettings
- GNOME 42
- Ubuntu 22.04 LTS
